# 通利华汽车集团后台功能与使用手册

版本 1.0　更新日期 2026年10月14日

本手册面向网站管理员、运营人员和客服人员，说明后台各模块的用途、操作方法及对官网的影响。后台主要用于维护已存在的车辆和配件、管理页面图片和新闻、跟进客户线索，以及维护企业资料和数据备份。

日常工作可按“查看运营总览 → 处理询盘和消息 → 检查库存 → 更新图片和新闻 → 核对官网 → 备份”的顺序进行。各章节中的“当前限制”属于本版本实际功能边界。

## 一 登录与快速上手

### 1 后台入口

使用网站域名加 `/admin/` 访问后台。例如，站点域名为 `https://tlhdd.cn` 时，后台入口为 `https://tlhdd.cn/admin/`。本地默认入口为 `http://127.0.0.1:4173/admin/`，前提是本地服务已启动。

输入管理员账号和密码，点击登录，进入“运营总览”。网站前台的注册账号不等同于管理员账号；账号由系统维护人员提供。首次初始化用的环境变量不会自动覆盖已有管理员密码。

管理员登录会话有效期为 8 小时。会话失效后需要重新登录；工作结束后从用户菜单退出登录。忘记密码时联系维护人员处理，当前后台没有自助找回密码或管理员账号管理页面。

### 2 常用任务入口

| 要做的事情 | 从这里进入 |
| --- | --- |
| 查看待处理线索和库存情况 | 运营总览 |
| 上下架车辆或配件 | 车辆管理、配件管理 |
| 替换首页业务图或轮播图 | 页面管理 → 页面配置 |
| 替换其他页面的横幅或配图 | 页面管理 → 页面内容 |
| 新增、编辑或定时发布新闻 | 新闻中心 |
| 查看客户需求并更新跟进状态 | 询盘管理 |
| 查看在线咨询摘要并标记状态 | 在线消息 |
| 查询网站注册账号 | 注册用户 |
| 修改联系方式、公告或下载备份 | 系统设置 |

### 3 操作生效规则

列表中的状态开关、状态下拉框、图片替换和删除操作会直接提交服务器，出现成功提示后即已保存。“系统设置”需要点击“保存设置”；新闻编辑需要点击“保存草稿”或“保存并发布”。

修改后打开对应官网页面并刷新检查。后台大多数列表在进入页面或点击“刷新”时重新读取数据，不应把停留在页面上的数字当作持续自动更新的数据。搜索无结果时先清空关键词、状态和类型筛选。

“停用”保留记录，通常可重新上架或启用；“删除”永久删除数据库记录，后台没有回收站和一键撤销。暂时不展示车辆或配件时，优先使用停用。

## 二 后台功能总览

后台共 11 个业务页面，“页面配置”和“页面内容”位于“页面管理”分组下。

| 功能页面 | 当前可执行的主要操作 | 当前主要边界 |
| --- | --- | --- |
| 运营总览 | 查看线索、库存、最近更新车辆和快捷入口 | 无流量、成交或财务报表 |
| 车辆管理 | 搜索、筛选、分页、上下架、单条及批量删除 | 无新增和详情编辑表单 |
| 配件管理 | 搜索、筛选、分页、上下架、单条及批量删除 | 无新增和详情编辑表单 |
| 页面配置 | 查看首页配置、切换启用状态、替换及清除图片、删除记录 | 无文字和排序编辑表单 |
| 页面内容 | 查看其他页面区块和素材、替换及清除图片、删除记录 | 状态以标签显示，无通用状态开关 |
| 新闻中心 | 新增、编辑、草稿、发布、定时展示、多语言、封面和正文图片、删除 | 无独立草稿预览或审核流 |
| 分类标签 | 查看分类与标签、刷新、删除 | 无新增、改名和启停入口 |
| 询盘管理 | 搜索、筛选、查看联系方式和需求、修改状态、删除 | 无报价单、负责人和备注编辑入口 |
| 在线消息 | 搜索、筛选、查看最近消息摘要、修改状态、删除会话 | 无完整对话窗口和直接回复入口 |
| 注册用户 | 查询用户资料、搜索、删除账号及关联数据 | 无权限修改、禁用或重置密码入口 |
| 系统设置 | 修改全站资料和文案、修改本人管理员密码、下载数据库备份 | 无在线导入恢复或管理员分权界面 |

后端接口具备部分更广的写入能力，但操作手册中的步骤以当前后台实际提供的按钮和表单为准。

## 三 运营总览

该页面用于安排当天的跟进和维护工作，展示以下指标。

| 指标 | 计算口径 |
| --- | --- |
| 待处理线索 | 状态为“新询盘”的数量，加上待回复或管理员未读的消息会话数量 |
| 库存总量 | 全部车辆记录数，含新车、二手车和停用车辆；不含配件 |
| 已上架车辆 | 启用的车辆记录数 |
| 已上架配件 | 启用的配件记录数 |
| 最近更新车辆 | 按更新时间倒序显示最近 5 条车辆记录 |
| 库存健康度 | 停用车辆、推荐车辆、启用首页轮播及待回复消息数量 |

操作时先查看待处理线索，再进入“询盘管理”和“在线消息”处理；库存存在缺图记录时，进入“车辆管理”选择“缺少图片”筛选。“管理车辆”“配置首页”提供快捷跳转。

“待处理线索”按询盘记录和会话分别计数，不是去重后的客户数。消息会话只要仍为管理员未读，就可能继续计入总览，即使已改为“已处理”。当前消息列表没有标记已读入口，不能仅靠修改状态保证该数字清零。

“缺少图片”检查主图地址是否为空，不会检测地址失效、文件丢失或所有相册图片是否完整。

## 四 车辆管理

### 1 查看与筛选

列表显示车辆名称、新车或二手车类型、品牌与车型、价格、上架状态及操作。输入车辆名称、品牌或车型后按回车或点击搜索，结合下列条件定位记录。

| 筛选项 | 可选条件 |
| --- | --- |
| 车辆类型 | 全部、新车、二手车 |
| 车辆状态 | 全部、已上架、已停用、推荐车辆、缺少图片 |
| 每页条数 | 12、24、50、100；默认 12 |

筛选会从第一页重新显示；“共多少辆”表示当前筛选条件下的总量。推荐筛选用于查询已有推荐标记，当前列表不能修改推荐标记。

### 2 上架与停用

1. 搜索并核对车辆名称、类型和品牌车型。
2. 点击该行“上架状态”开关，切换为“上架”或“停用”。
3. 等待“车辆状态已更新”提示，再刷新官网新车或二手车列表检查。

停用后车辆不再作为启用库存展示，记录仍保留在后台。当前页面不能修改名称、价格、车型、车辆说明、图片或排序，也不能新增车辆。相关维护需由维护人员通过现有接口或开发工具处理。

### 3 单条与批量删除

单条删除：核对目标行 → 点击“删除” → 阅读永久删除提示 → 确认。删除后车辆记录无法在后台恢复。

批量删除：点击“批量删除” → 勾选当前页记录，或勾选表头选择当前页全部记录 → 核对“删除选中”的数量 → 点击该按钮 → 点击“确认删除”。点击“取消多选”可退出选择模式。

每次最多删除 100 条，仅选择当前页记录；翻页、改变筛选或刷新都会清空已选记录。选择后若其中某条已被其他操作删除，整批不会执行，需要刷新后重新选择。批量操作删除库存数据库记录，不应将其理解为同时清理所有上传图片文件。

## 五 配件管理

列表显示配件名称、配件编号、分类、价格、上架状态及操作。可按名称、编号、品牌或适配车型搜索，并按“已上架、已停用、推荐配件、缺少图片”筛选。

每页可显示 20、50 或 100 条，默认 50 条。上下架、单条删除和批量删除的操作方法与车辆管理相同，批量选择同样仅限当前页且最多 100 条。

上架状态影响官网配件目录及详情的可见性。当前后台不能新增配件、修改配件详情和价格、替换配件主图或调整推荐标记。官网“服务中心”的页面配图应在“页面内容”维护，与商品记录中的配件图片分开管理。

## 六 页面管理

“页面配置”管理首页，“页面内容”管理其他页面。区块是页面的一组内容，内容项是区块下的单条卡片或条目，素材位则对应固定图片位置。先确定目标页面和图片位置，再选择对应标签页。

### 1 页面配置

进入“页面管理 → 页面配置”，按需要切换标签页。

| 标签页 | 主要内容 | 可用操作 |
| --- | --- | --- |
| 首页轮播 | 标题、说明、轮播图、排序、状态 | 替换或清除图片、启停、删除记录 |
| 首页数据指标 | 指标名称、数值、排序、状态 | 查看、启停、删除记录 |
| 首页内容区块 | 区块标识、名称、标题、配图、排序 | 替换或清除图片、启停、删除记录 |
| 首页区块内容项 | 所属区块、内容标题、配图、排序 | 替换或清除图片、启停、删除记录 |
| 首页素材 | 业务图、价值观图、品牌墙、背景等固定素材位 | 替换或清除图片、符合条件时还原默认、启停、删除素材位 |

根据名称和缩略图确认目标后再操作。开关会即时保存；页面没有统一的“保存全部”按钮。排序、指标值和标题虽然可查看，但当前没有对应编辑表单。

### 2 页面内容

进入“页面管理 → 页面内容”，可查看“页面区块”“区块内容项”“页面素材”三个标签页。区块和内容项支持查看、替换或清除配图、删除记录；页面素材还可在存在默认素材时还原默认。状态列仅显示“启用”或“停用”标签。

“页面素材”通过“所属页面”识别位置，常见标识如下。

| 页面标识 | 官网页面 |
| --- | --- |
| about | 走进通利华 |
| new-cars、used-cars | 新车出口、二手车出口 |
| new-car-detail、used-car-detail | 新车详情、二手车详情 |
| car-options | 汽车选装 |
| transportation | 物流运输 |
| purchase-plan | 购买方案 |
| service-center | 服务中心 |
| contact、part-detail、user-center | 联系我们、配件详情、用户中心 |

首页区块使用 `index` 标识，首页固定素材使用 `home` 标识，二者都归入“页面配置”。当前“页面内容”未提供按页面筛选或搜索入口，可通过所属页面列和分页定位。具体记录随站点实际数据变化。

### 3 替换图片

1. 找到目标记录，核对名称、所属页面和当前缩略图。
2. 点击“替换图片”，选择 JPG、JPEG、PNG 或 WebP 文件，单张不超过 20MB。
3. 等待上传和保存结束，出现“图片已替换”提示。
4. 刷新对应官网页面，检查清晰度、裁切、文字遮挡及手机端效果。

图片会生成优化版本和缩略图。建议事先裁切成接近原图的宽高比例；后台上传成功不代表每个屏幕下的裁切都合适。普通图片选择器不支持上传 SVG、GIF 或视频；部分默认图片本身是 SVG，仍可用支持的位图格式替换。

### 4 清除图片与还原默认

“删除图片”只清除当前图片引用，保留对应记录和位置；对于页面素材位，同时停用该素材。需要重新展示时，可以再次替换图片。

“还原默认”只在记录有默认图片地址且当前图片不同于默认值时显示。还原会恢复默认图片并启用该素材位。轮播、区块和内容项没有默认地址时，不提供此按钮。

行末“删除”或“删除记录”会删除整条配置。删除一个页面区块时，其下全部内容项也会一并删除；删除素材位后，该行从后台消失，无法再使用它的还原按钮。重启服务不会自动恢复已删除的默认记录。

固定素材位的清除或删除会让绑定位置停止展示图片；区块的停用或删除对页面的影响取决于官网绑定方式，个别位置仍可能显示原有静态文案或布局。操作后必须查看官网，不能把删除配置记录当作删除整个页面。

### 5 当前内容编辑范围

这两个页面没有新增区块、编辑多语言文字、修改链接或调整排序的通用表单。企业资料及部分全站文案在“系统设置”修改，新闻在“新闻中心”修改，其他未开放的页面文字和结构由维护人员处理。

## 七 新闻中心

新闻中心统一管理官网首页新闻展示、新闻列表和新闻详情。支持“公司资讯”“行业动态”两种分类，以及中文、英文和俄文内容。

### 1 新增与保存草稿

1. 点击“新增新闻”，选择分类，发布状态保留“草稿”。
2. 填写中文标题和正文，按需填写摘要、文章来源和排序。
3. 上传封面图片；正文中的图片通过编辑器“插入图片”单独添加。
4. 按需切换 English 或 Русский 标签页填写译文。
5. 点击“保存草稿”。草稿只在后台显示，不会出现在官网。

| 字段 | 填写规则 |
| --- | --- |
| 中文标题 | 必填，最多 300 字 |
| 中文正文 | 必填，需要有效文字内容；仅插入图片不能代替正文 |
| 英文和俄文 | 选填，未填写的对应内容会回退显示中文 |
| 摘要 | 选填，每种语言最多 2000 字；留空时前台摘取正文 |
| 文章来源 | 默认“通利华汽车集团”，最多 200 字 |
| 封面图片 | 用于首页等新闻预览；支持的图片格式同页面图片，最大 20MB |
| 排序 | 整数，范围为 -1000000 至 1000000；数字越小越靠前 |
| 发布时间 | 按北京时间填写；发布状态下留空使用当前时间 |

正文工具栏支持正文、小标题、加粗、列表、插入图片和撤销。从其他文档粘贴时按纯文本处理，不保留原有字体、颜色和排版。正文图片要通过“插入图片”上传，不能依靠粘贴 Word 图片完成。

上传图片后仍需保存新闻，图片引用才会随文章保存。上传或保存期间等待操作完成，避免关闭编辑窗口。

### 2 立即发布与定时展示

立即发布：编辑文章 → 将发布状态设为“发布” → 发布时间留空或设为已到时间 → 点击“保存并发布” → 刷新官网检查。

定时展示：将发布状态设为“发布”，填写未来的北京时间，再点击“保存并发布”。后台显示“定时发布”，官网在该时间之前不会列出文章，直接访问详情也不会显示。到达时间后，官网在下一次加载新闻数据时展示；已经打开的页面需要刷新。

发布时间不会自动改变草稿状态。草稿即使填写了未来时间，仍需把状态改为“发布”才能按时展示。例：希望在2026年10月20日09时上线，应选择“发布”并填写该北京时间。

新闻按排序数字升序排列，相同排序时按发布时间倒序，仍相同再按记录 ID 倒序。首页仅展示当前可见新闻中的前 3 篇，已发布文章不一定都能出现在首页。

### 3 编辑与查看

在列表搜索标题或来源，可按“草稿”或“已发布 / 定时发布”筛选；点击标题或“编辑”进入表单。修改已发布新闻并保存后，官网会在重新加载时显示新内容。

已发布且已到展示时间的文章提供“查看”入口，打开官网详情页。草稿和未到时间的文章没有独立官网预览入口。将文章改回“草稿”并保存可撤下展示，保留后台记录。

点击“取消”或关闭窗口时，如有未保存修改，会提示放弃或继续编辑。此保护针对编辑窗口关闭，不应作为浏览器刷新或关闭标签页时的自动保存保障。

### 4 删除新闻

点击“删除”并确认后，文章从首页、列表和详情中移除，旧详情链接将无法找到该文章。若只是临时撤下，建议改为草稿。删除文章不会自动清理其已上传的全部图片文件。

## 八 分类标签

该页面展示分类和标签的适用范围、类型、名称、系统标识、内置或自定义属性、启用状态。当前可查看、翻页、刷新和删除，每页 20 条。

删除时核对适用范围与显示名称，再点击“删除”并确认。内置项也可删除，且不会因重启自动恢复。删除分类或标签不会同时删除车辆或配件，但可能影响官网筛选入口和分类显示；删除后检查相关目录。

当前没有新增、修改名称、多语言翻译、排序或启停按钮。需要调整分类结构时，由维护人员处理。

## 九 询盘管理

询盘记录来自官网客户提交的车型或服务需求。列表包含联系人、联系方式、意向车型或需求、目的地、状态和提交时间。

### 1 查询与跟进

1. 按联系人、联系方式、车型或目的地搜索，或选择状态筛选。
2. 查看客户需求和联系方式，通过实际电话、邮箱或其他业务渠道联系客户。
3. 在目标行的状态下拉框中选择新的状态，等待成功提示。
4. 如需确认当前筛选结果，点击“刷新”。

| 状态 | 建议业务含义 |
| --- | --- |
| 新询盘 | 刚收到，尚未开始联系 |
| 跟进中 | 已联系，继续确认需求 |
| 已报价 | 已通过实际业务渠道提供报价 |
| 已关闭 | 本次需求处理结束 |

建议按“新询盘 → 跟进中 → 已报价 → 已关闭”跟进，系统允许按实际情况直接选择状态。状态修改只是业务标记，不会自动发送通知、邮件、报价单或生成订单。

每页显示 15 条。删除询盘会永久删除其联系方式和需求记录；正常完成的需求应标记“已关闭”，保留业务历史。

### 2 当前限制

页面没有询盘详情编辑窗口、客服备注、负责人分配、报价文件上传和批量导出入口。需求列优先显示意向车型，未填写时才显示留言，不能保证该列同时呈现全部留言内容；需要完整原始需求时联系维护人员查询。

## 十 在线消息

在线消息用于汇总官网访客和注册用户的在线咨询。列表显示客户、联系方式、主题或商品、最近消息、状态和更新时间。最近消息最多展示约 52 个字符，超出部分用省略号显示。

可按客户、联系方式、商品或消息内容搜索，按状态筛选，每页显示 15 个会话。通过操作列的下拉框标记“待回复”“跟进中”或“已处理”，选择后即时保存。

当前后台仅提供会话列表和最近消息摘要，没有打开完整聊天记录、输入回复或发送消息的窗口。实际联系客户应使用已提供的联系方式；不要把“已处理”状态视为系统已经向客户发送回复，也不要据此认定管理员未读标记已清除。

删除会话会同时永久删除全部聊天消息。已完成的咨询建议标记为“已处理”保留历史，误删只能依靠适用的数据备份恢复。

## 十一 注册用户

列表用于查询网站前台注册用户，显示姓名、账号、公司、邮箱、电话、角色、注册时间和最近登录时间。搜索支持姓名、账号、公司、角色，也可匹配邮箱和电话，每页 15 条。

“角色”是用户记录中的资料，不能在本页修改，也不代表可以把该用户提升为后台管理员。当前没有新增用户、编辑资料、禁用账号、重置用户密码和分配管理员权限的入口。

删除账号前应特别核对目标。点击“删除用户”并确认后，会删除该用户及其关联询盘、消息会话及聊天记录、论坛帖子、上传额度记录和登录会话。该操作不是单纯隐藏账号；上传素材文件不作为同一操作自动清理。

## 十二 系统设置

### 1 企业资料与全站内容

修改字段后点击“保存设置”，等待成功提示，再刷新相应官网页面核对。“重新加载”会从服务器重新读取设置，未保存的编辑会被覆盖。

| 字段组 | 可编辑项目 | 主要用途或范围 |
| --- | --- | --- |
| 企业资料 | 公司名称、服务时间、电话、邮箱、WhatsApp、微信、地址 | 公司名称、电话、邮箱和地址用于官网绑定位置；WhatsApp 用于浮动联系入口；微信可保存，当前公共脚本未绑定展示 |
| 页脚 | 页脚简介 | 更新官网公共页脚说明 |
| SEO | SEO 标题、SEO 描述 | 标题用于首页；描述作用于已有描述标签的页面，部分页面脚本会自行设置标题 |
| 公告 | 站点公告 / 顶部提示 | 非空时展示顶部公告，清空后取消该公告 |
| 二手车列表 | 二手车列表标题、二手车列表说明 | 更新二手车列表对应文案 |
| 二手车详情 | 详情页描述标题、详情页默认描述 | 当前表单这两项对应二手车详情；默认描述用于车辆缺少对应描述时 |
| 样式 | 自定义样式 | 将 CSS 应用于官网，建议由维护人员修改 |

WhatsApp 可填写带国家区号的号码或完整网页链接。号码会转换为 WhatsApp 联系链接；为空或无法生成链接时，浮动联系入口回到联系页。

系统设置没有独立的中英俄文编辑标签页，不会自动翻译新填写的业务文字。部分空字段在官网存在默认值回退，所以清空不一定意味着隐藏；“站点公告”清空则会取消公告。修改后应分别检查需要使用的语言和页面。

### 2 修改管理员密码

进入“修改管理员密码”，填写旧密码和至少 12 位的新密码，点击“更新密码”。成功后该管理员已有登录会话失效，需要使用新密码重新登录。

建议使用随机强密码。此操作只修改当前管理员本人密码，不能为其他管理员或前台注册用户重置密码。

### 3 下载数据备份

点击“下载数据备份”，浏览器开始下载以 `tlhdd-mysql-` 开头的 `.sql` 文件。确认文件下载完成，并将备份存放在受限访问的位置。

数据库备份包含业务数据和账号相关记录，不包含有效登录会话，也不包含 `uploads/` 下的图片、视频等文件。完整备份必须同时保存数据库和上传目录；仅有 SQL 文件不能恢复全部媒体。

建议在批量删除或大范围调整前备份，日常定期备份并安排恢复验证。后台没有上传 SQL 或一键恢复按钮，恢复由维护人员执行。备份 SQL 含有重建表语句，直接导入现有业务库可能覆盖当前数据，应先在隔离环境验证恢复结果。

## 十三 常用操作流程

### 1 每日客服工作

登录后查看“运营总览”，进入“询盘管理”筛选新询盘并联系客户，按实际进展修改状态；进入“在线消息”查看待回复咨询，通过客户联系方式跟进，完成后标记已处理。业务进展需要自行留存于实际使用的业务记录工具中。

### 2 替换首页业务图片

进入“页面管理 → 页面配置 → 首页素材”，根据“新车销售业务图”“二手车业务图”等名称找到记录，点击“替换图片”上传，等待成功后刷新首页，检查桌面和手机端。需要恢复旧默认素材时，使用该素材位的“还原默认”。

### 3 发布一篇新闻

新增新闻，填写中文标题和正文、摘要、分类、来源、封面与译文，先保存草稿并重新打开核对。确认后将状态改为发布，设置北京时间，点击“保存并发布”。立即发布的文章通过“查看”核对官网；定时文章到时间后再核对。

### 4 暂停展示一批商品

在车辆或配件列表通过筛选定位商品，逐条关闭上架开关并检查结果。当前“批量删除”用于永久删除，不提供批量停用；不能用删除代替临时下架。

### 5 清理无效数据

先下载数据库备份，并安排备份上传目录，核实目标记录和关联影响，再执行删除。商品可按当前页批量删除；用户、页面区块和消息会话的删除会影响关联记录，应逐条核对。

## 十四 常见问题

| 问题 | 检查与处理 |
| --- | --- |
| 登录失败 | 确认使用管理员账号，核对大小写和密码；提示频繁尝试时稍后重试；仍失败联系维护人员 |
| 操作提示未授权或需要重新登录 | 会话可能过期，或修改密码后会话已失效；重新登录后刷新确认结果 |
| 列表为空 | 清空搜索、状态和类型条件，再刷新；区分确实无数据与加载失败提示 |
| 图片上传失败 | 核对格式、20MB 大小限制及文件是否损坏；仍失败由维护人员检查图片处理依赖和服务器上传配置 |
| 图片保存成功但官网未变化 | 确认目标页面及素材位正确，刷新页面，检查记录是否启用；必要时由维护人员核对发布版本和资源访问 |
| 缺图筛选没有找到坏图 | 此筛选只检查主图地址为空；已有地址但文件失效需人工检查 |
| 找不到还原默认按钮 | 只有具有默认图片地址且当前值不同的素材位才显示；整条记录被删除后不能通过该按钮恢复 |
| 新闻保存后官网看不到 | 确认不是草稿，发布时间已到；检查列表与首页排序，首页只显示前 3 篇可见文章 |
| 英文或俄文页面仍显示中文 | 相应译文未填写时会回退中文；进入对应语言标签页补充并保存 |
| 消息已经处理但总览仍有待处理数 | 总览还包括未读会话和新询盘，修改消息状态不会自动清除管理员未读标记 |
| 批量删除提示记录不存在 | 整批尚未执行，刷新后重新勾选；翻页和筛选会清空原选择 |
| 下载备份失败 | 确认仍登录，稍后重试；由维护人员检查数据库权限和服务器日志 |
| 误删除记录 | 停止继续删除，联系维护人员评估备份和恢复范围；后台无撤销功能 |

以下入口用于核对后台菜单和代码，不要求运营人员手动调用接口。

| 新闻中心 | `/admin/#/news` | `/api/admin/news`、`/api/admin/news/{id}` |

页面图片与新闻图片使用 `/api/admin/upload-media`。当前页面操作以查询、PATCH 保存及 DELETE 删除为主，商品批量删除使用 POST。不要仅凭接口存在就向运营人员承诺界面上已有相应能力。

后台定制源码位于 `admin-vben/apps/web-antd/src/`，网站实际提供的后台构建文件位于 `admin/`。修改源码后需要构建并发布，才会影响网站实际后台。开发说明见 `admin-vben/README.tlhdd.md`，部署和回滚说明见 `deploy/production-runbook.md`。

本手册对应的代码核对位置包括：后台路由和 11 个业务页面、`AdminImageActions.vue`、`NewsEditor.vue`，以及 `admin_service.py`、`server.py`、`auth_service.py`、`content_service.py`、`catalog_service.py`、`chat_service.py`、`news_service.py`、`database.py`、`uploads.py` 和官网 `assets/js/main.js`、`assets/js/news.js`。
